# dahuja8.github.io

Personal website, served by GitHub Pages at https://dahuja8.github.io.

- `index.html`: the whole site (a single page)
- `assets/img/profile.jpg`: headshot
- `assets/img/pubs/`: paper thumbnails, cropped from each paper's teaser figure
- `assets/cv.pdf`: CV (not added yet; the CV link points here)

Preview locally with `python3 -m http.server 8585` and open http://localhost:8585/.
